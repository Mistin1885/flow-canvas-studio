編輯與保存流程

瀏覽： 左側提供圖面定位與子流程；搜尋涵蓋節點名稱、內容、屬性與節點 ID。專案步驟預設全開，點節點查看完整內容。

編輯： 按「新增節點」可先建立獨立節點，再從編輯器加入前序與後續連線。節點角色可直接選擇，分類可複選，也可新增名稱與顏色。

來源： 箭頭對照工作表的連接線；外框可作為端點，框內步驟可獨立查閱。來源清單保留人工核對紀錄。

子流程： 點節點的 − 可收合後續分支，點 ＋ 一次展開整條分支。其他路徑仍連得到的節點會保留。子流程可由父節點的 ＋ 就地展開；多組可同時展開。左側捷徑可定位到第一步；內嵌來源圖片可離線查看。

保存： 團隊網站會同步已套用的變更。下載的 HTML 可獨立離線編輯，離線變更須重新下載保存。

匯入： 支援原始 dfx-flow-extraction/0.1 草稿，以及本版匯出的 dfx-project-flow JSON。套用前可預覽節點差異，之後可復原上次匯入。

JSON 規則

nodes 保留穩定 ID；edges 決定實際連線。drawingBox 與 drawingRoute 記錄原圖位置和線路。navigation 是側邊捷徑。subflows 記錄父節點與子流程的對應；sourceData 保存原始擷取資料；review 保存待確認連線及人工確認紀錄。
